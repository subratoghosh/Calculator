🧮 Calculator

A simple and responsive Calculator web application built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with a clean and intuitive user interface, providing a smooth user experience across desktop and mobile devices.

🚀 Live Demo

🌐 Live Website: Calculator Demo

✨ Features
Basic arithmetic operations
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Clear and delete functionality
Responsive design for mobile and desktop
Real-time calculations
Clean and user-friendly interface
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
